使用说明

这一页能打开，就说明 App 认得里面的网页了。下面这几步就是在手机上翻本地网页的全部方法。

1. 导入一整个文件夹

  1. 回首页，点底下的「添加文件」
  2. 选「选文件夹」，找到装着网页的那一层（有 index.html 的那层）
  3. 系统会问你要一次权限，允许
  4. 回首页，它会出现在「站点」里，点进去就能翻

一定要整个文件夹一起进来。网页里的跳转是一条条相对路径，少一张图、少一个页面，翻到一半就白屏。

2. 为什么文件会复制一份进来

手机原位置的网页被系统挪走、或者相册清了，链接就断了。复制进来以后，外面怎么整理都跟它没关系。代价是占地方：网页多大就占多大。

3. 为什么两指放不大

很多网页没写缩放规则，双指一碰整页就跑偏，按钮点不中。所以默认锁死。要放大得去设置里开，而且只对网页内容生效，App 自己的界面永远不动。

4. 几点要留意的

不联网：这个 App 没有联网权限，网页里写的外链点了会交给系统浏览器。

只读本地：只会读你自己导进来的东西，不会去翻别的文件夹。

网页的样子它不改：页面长什么样就是原作者写的什么样，App 只加了上面那条返回栏。
