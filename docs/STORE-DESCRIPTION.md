> ⚠️ **本版本为体验版（1.1.1），可能不稳定。** 功能、界面与接口都可能随时调整，请勿用于正式或关键用途。遇到问题欢迎反馈，但请先备份重要文件。

## 一句话

把手机里的网页文件夹导进来，不联网也能翻——跳转、图片、子文件夹都照旧。

## 完整描述（商店用）

**它是什么**

一个只读本地的网页浏览器。把手机上现成的网页文件（一整个文件夹，或者单个 .html）导入进来，之后不用联网、不用装任何插件，就能像浏览普通网站那样在页面之间跳转。

适合这些场景：离线保存的说明书和教程、自己做的整理页和笔记页、别人发给你的网页资料、从电脑拷过来的静态站点。手机原文件删了也不影响——导入时已经复制进 App 自己的目录。

**主要功能**

- 整文件夹导入，保留全部目录层级和子文件夹
- 也可以只导入单个 .html 文件
- 首页按「站点」「单独导入的文件」分区列出，带页面数、占用大小和导入时间
- 内置《使用说明》和《示例站点》两个演示页，装好就能试
- 深色 / 浅色 / 跟随系统三种主题
- 网页默认锁定缩放，可在设置里开启双指缩放
- 环境自检：8 项运行环境检查，出问题先看这一页
- 日志：最近 1000 条，超过 512 KB 自动截断，可一键导出到「下载/LocalHttp」
- 从文件管理器点「用其他应用打开」一个 .html，会直接收进本 App

**隐私：它没有网络权限**

安装时不会向系统申请任何权限，连联网权限都没有——这是应用清单里写死的，不是「承诺不联网」。所有页面都从手机本地文件读取，不上传、不统计、不要账号、不含广告和第三方 SDK。

**下载内容存在哪里**

导入的文件会被复制到 App 自己的私有目录。卸载 App 会一并删除。原始文件没有任何改动。

**已知限制，请先看清楚**

- **这是体验版，可能不稳定。** 崩溃、页面白屏、导入中断都可能在所难免，重要文件请先自行备份
- **最低系统 Android 14**，更低版本的手机装不上
- 功能与接口仍可能调整，升级后设置或导入方式可能有变化
- 只认本地网页文件，**没有地址栏，不能输入网址上网**，也不会帮你下载网上的页面。要上网请用系统浏览器
- 网页里的外链点击后会交给系统浏览器打开
- 依赖手机自带的 WebView 内核渲染。个别网页用到较新的 CSS 或 JS 特性时，显示效果可能和电脑上不同
- 建议只导入你自己信任的网页文件
